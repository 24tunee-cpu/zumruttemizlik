# Competitor intel — hard stops (AGENTS üstün)

Garrett `local-competitor-analysis` / Whitespark tarzı öneriler **filtrelenir**.

## Asla önerme / uygulama

- GBP işletme adına keyword stuffing (“Sarıyer Temizlik …” vb.)
- Sahte / satın alınmış yorum; burst review kampanyası
- Sahte şube, sanal ofis, pin “distance hack”
- Rakibin spam taktiğini kopyalama (çoklu listing, yanlış kategori)
- İnce / kopya mahalle sayfası spam (doorway)
- Peyzaj / bahçe düzenleme hizmeti uydurma
- Indexing API = “Google’a ping”; IndexNow’u Google keşfi diye satma
- Onaysız ücretli MCP (LocalSEOData, BrightLocal, Ahrefs, Semrush, Local Falcon)
- Uydurma sıralama / trafik / “rakipten %X öndesin” iddiası

## Spam rakip görürsen

1. Matrise “spam şüphesi” notu  
2. Kullanıcıya Google’a bildirim seçeneğini hatırlat  
3. Bizde meşru sütunları güçlendir (yorum hızı, foto, services, semt içerik)
