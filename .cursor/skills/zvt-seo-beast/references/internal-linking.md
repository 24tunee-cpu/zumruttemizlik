# İç link standardı

## Araçlar

- `src/lib/internal-seo-links.ts`  
- `RelatedSeoLinks`  
- Blog publish auto links (marker)  
- Home hub strip (semt×hizmet + SSS)

## Minimum set

| Sayfa tipi | En az |
|------------|--------|
| İlçe hub | 3 hizmet pair + 1 yakın ilçe + CTA |
| Semt | Semt×hizmet (varsa) + ilçe hub + 2 hizmet |
| Hizmet | 2 öncelik ilçe + fiyat/randevu |
| Blog | 1 hizmet + 1 bölge hub (marka zayıflatma yok) |
| SSS topic | Hub `/sss` + ilgili hizmet/bölge |

Orphan URL üretme. Yeni landing → en az bir hub’dan link.
