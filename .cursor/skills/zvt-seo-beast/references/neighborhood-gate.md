# Neighborhood / semt×hizmet kapısı

## Kabul (hepsi zorunlu)

- [ ] Operasyonel özgün paragraf (≥3 body) — semt gerçekleri (villa/plaza/orman/Boğaz vb.)  
- [ ] En az 3 özgün FAQ (kopya ilçe FAQ değil)  
- [ ] Peyzaj yok; bahçe varsa “yüzey temizliği”  
- [ ] Soft claim; “her adres her gün” yok  
- [ ] Featured services gerçek seed slug  
- [ ] Meta clamp  
- [ ] `generateStaticParams` / sitemap lastmod bump  
- [ ] İç link: semt hub ↔ hizmet ↔ CTA  

## Red

- İlçe adını değiştirip aynı metin  
- 18 ilçeye otomatik mahalle spam  
- Sadece keyword H1  
- Doğrulanmamış “en iyi #1”  

## Örnek iyi slug’lar

`zekeriyakoy`, `maslak-ofis-temizligi` — niyet ayrışmış, operasyonel detay var.
