# GBP panel checklist (manuel)

Google: relevance / distance / prominence. Tam profil + tutarlı NAP = relevance.

## Temizlik (P0)

- [ ] Peyzaj Mimarı kaldır  
- [ ] Tekne yoksa kaldır  
- [ ] Açıklamadan peyzaj çıkar  
- [ ] Ad = Zümrüt Vadi Temizlik (keyword stuffing yok)

## Tamamlık

- [ ] Birincil: Temizlik Hizmetleri  
- [ ] İkincil: Ofis, İnşaat sonrası, Ev, Cam, Halı, Koltuk (mevcut hizmetler)  
- [ ] Saat: 24 saat (site schema ile aynı)  
- [ ] Web: `https://www.zumrutvaditemizlik.com` (+ UTM opsiyonel)  
- [ ] Telefon / adres = `site-contact`  
- [ ] Hizmet alanı: öncelik Sarıyer + Avrupa Yakası (hibrit pin koru)

## Prominence operasyon

- [ ] Fotoğraf ekle (önce/sonra, ekip) — stok azalt  
- [ ] Haftalık Post  
- [ ] Yorum: **düzenli velocity** (burst spam değil); her yoruma yanıt  
- [ ] Q&A: gerçek sorular  

Kaynak: [Google local ranking tips](https://support.google.com/business/answer/7091). Sektör: fotoğraf + kategori + review recency önemli; garanti yok.
