# CTR benchmark & SERP

Yaklaşık organik CTR (Garrett / endüstri ort.; marka ve SERP feature sapması büyük):

| Poz | Beklenen CTR |
|-----|----------------|
| 1 | 25–35% |
| 2 | 12–18% |
| 3 | 8–12% |
| 4–5 | 5–8% |
| 6–10 | 2–5% |
| 11–20 | 0.5–2% |

Pozisyona göre CTR bariz düşükse → title/meta/H1 (`gsc-ctr-overrides.ts` / pair meta).  
Poz iyi CTR kötü + AI Overview/snippet → “ücretsiz keşif / fiyat / ara” niyeti güçlendir; sahte yıldız schema yok.
